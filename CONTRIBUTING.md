# Contribution guidelines

- All contributions of any kind are highly appreciated.
- Review times may vary, but eventually will be carried out.
- Know the license, under which your code will be released if accepted.
- When writing code, be reasonable about features and pay extra attention to maintainability.
- Please check your code at best effort for common pitfalls such as:
  compilation failures, formatting, typos, non-existent links, inconsistencies in general  
  using this may involve a good `pre-commit` hook (see my [`rust-pre-commit`](https://codeberg.org/jark/thot-files/src/branch/main/scripts/rust-pre-commit) for reference)  
  otherwise they will _hopefully_ be caught in CI and thrown back at you

## AI Usage Policy

This project has strict rules for AI usage:

- **You must state if/how you used AI.**
  This includes the tool you used along with the extent that the work was AI-assisted.

- **You must fully understand all code.**
  You have to write/edit the PR/issue description yourself.

- **No AI-generated media is allowed (images, videos, etc.).**
  Text and code are the only acceptable AI-generated content, per the other rules in this policy.

- **Bad AI drivers will be denounced.**
  People who produce bad contributions that are clearly AI (slop) will be added to our public denouncement list.

These rules apply to outside contributors more strictly, as code owners have already gained trust, that they follow them rationally.

### This project is made for and by humans

Please remember that this project is primarily written and maintained by humans who have limited time
and so want to spend it sensibly, not by staring at crap produced by machines.

### AI is Welcome Here

This project is written with the help of AI assistance to a reasonable extent,
and AI tools make sense as a productive tool.

**The reason for the strict AI policy is not due to an anti-AI stance**, but
instead due to the number of highly unqualified people using AI.

I include this section to be transparent about the project's usage about
AI for people who may disagree with it, and to address the misconception
that this policy is anti-AI in nature.
